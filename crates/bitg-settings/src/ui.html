    Aqlli tuzatishlar
    Inglizcha so'zlarga tegmaslik check, show, Obama's o'zgarmaydi. O'zbekcha gap ichidagi «chat» esa çat bo'ladi.
    Tushib qolgan apostrofni tiklash ozbek → özbek, togri → töğri. Lug'atdagi so'zni ham tuzatadi: Qirgiziston → Qirğiziston. Ikki ma'noli so'zlar (qol, oz, yoq) tegilmaydi. Yozganingiz aynan qolsin desangiz — o'chiring yoki so'zni Lug'atga qo'shing.
    Kirill harflarni ham o'girish шаҳар → şahar. O'chirilsa, kirillcha so'zlar o'zgarmaydi.
    Backspace bilan bekor qilish So'z o'girilgandan keyin darhol Backspace — asl so'z qaytadi (shu dasturda boshqa o'girilmaydi).
