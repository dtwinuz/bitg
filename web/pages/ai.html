MCP nima

MCP (Model Context Protocol) — AI yordamchilarga tashqi vosita ulash uchun ochiq standart. bitg serveri bitta vosita beradi: convert_text. U matnni eski lotin yoki kirilldan yangi alifboga, kerak bo‘lsa teskari — eski lotinga yoki kirillga o‘giradi.

Claude’ga bitg’ni qanday ulayman?

Claude.ai yoki Claude Desktop: Settings → Connectors → Add custom connector, manzil: https://bitg.uz/mcp. Claude Code’da:

/plugin install bitg --marketplace dtwinuz/bitg

Plagin bilan birga «yangi alifbo» ko‘nikmasi (skill) ham o‘rnatiladi: Claude o‘zbekcha javobni yangi alifboda yozishda bitg’dan o‘zi foydalanadi.

ChatGPT’da ishlaydimi?

Ha. ChatGPT sozlamalarida Apps bo‘limida dasturchi rejimini yoqing va yangi ilova sifatida https://bitg.uz/mcp manzilini qo‘shing. ChatGPT katalogiga rasmiy ilova sifatida joylash ko‘rib chiqilmoqda.

Gemini va boshqa dasturlarda-chi?

Gemini CLI: gemini extensions install https://github.com/dtwinuz/bitg. VS Code, Cursor va MCP’ni qo‘llaydigan boshqa dasturlarda HTTP MCP server sifatida shu manzilni qo‘shing. Server rasmiy MCP Registry’da uz.bitg/bitg nomi bilan.

Matnim saqlanadimi?

Yo‘q. Matn faqat o‘girish uchun xotirada ishlanadi, diskka va logga yozilmaydi. Server faqat IP manzil bo‘yicha so‘rovlar sonini cheklaydi (daqiqasiga 120 ta). Maxfiy hujjatlar uchun internetsiz ishlaydigan bitg dasturini yoki brauzerda ishlaydigan konvertorni tanlang — batafsil maxfiylik sahifasida.

Dasturchilar uchun

Transport: Streamable HTTP (POST /mcp, JSON javob), holatsiz, autentifikatsiyasiz. Vosita annotatsiyasi: faqat o‘qiydi (readOnlyHint). Manba kodi: bot/src/mcp.rs, ulash fayllari: integrations/.
