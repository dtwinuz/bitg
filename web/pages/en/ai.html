What it does

The server exposes one read-only tool, convert_text. It converts Uzbek text from the old Latin alphabet (o‘ g‘ sh ch, any apostrophe) or Cyrillic to the new Uzbek Latin alphabet adopted in 2026 (Ö Ğ Ş Ç), and back to old Latin or Cyrillic. It is the same deterministic engine as the bitg.uz converter and the bitg keyboard, with dictionaries for English words, names and exceptions.

How do I connect it to Claude?

In Claude.ai or Claude Desktop: Customize → Connectors → Add → Custom connector, URL https://bitg.uz/mcp, authentication “No sign-in”. In Claude Code:

/plugin install bitg --marketplace dtwinuz/bitg

The plugin also installs a “new alphabet” skill, so Claude uses bitg on its own when it writes Uzbek.

Does it work in ChatGPT?

Yes. In ChatGPT settings, enable developer mode under Apps and add a new app with the URL https://bitg.uz/mcp.

What about Gemini and other clients?

Gemini CLI: gemini extensions install https://github.com/dtwinuz/bitg. In VS Code, Cursor and any other client that supports remote MCP, add an HTTP server with the same URL. The server is listed in the official MCP Registry as uz.bitg/bitg.

Is my text stored?

No. Text is converted in memory and returned; it is never written to disk or logged. The server keeps the caller’s IP address in memory for one minute only to enforce a rate limit of 120 requests per minute. See the privacy policy. For confidential documents, use the offline bitg app or the in-browser converter.

For developers

Transport: Streamable HTTP (POST /mcp, JSON responses), stateless, no authentication. Protocol revisions 2026-07-28 (server/discover) and 2025-11-25 down to 2024-11-05 (initialize). Tool annotations: read-only, idempotent. Inputs: text (up to 20,000 characters), direction (to_new, to_old, to_cyrillic), old_style (official, ascii). Source: bot/src/mcp.rs. Support: tech@bitg.uz or GitHub issues.
