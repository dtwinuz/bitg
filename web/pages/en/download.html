Install on Windows in three steps

  1. Open the file. Double-click {{msiName}}. The installer sets bitg up for all users (administrator rights are needed; it goes to C:\Program Files\bitg\).
  2. bitg starts by itself at the end of setup and adds its keyboard to the “Uzbek (Latin)” language.
  3. Pick it. Press Win + Space and choose bitg. Now type the old way in any app: “o‘zbek” → “özbek”.

Updating works the same way: open the new MSI. You don’t need to close Chrome or Telegram or restart the computer. No internet connection is needed — conversion happens on your machine.

Windows says “Windows protected your PC”. Is that normal?

Yes. The beta installer is not code-signed yet, so SmartScreen warns about an unknown publisher. Click “More info” → “Run anyway”. To be sure the file is ours, check its SHA-256 as shown below.

Verify the file

In PowerShell, the hash must match the SHA-256 above character for character. Since v0.3.1 you can also prove with the GitHub CLI that the file was built by GitHub Actions from the dtwinuz/bitg repository:

Get-FileHash .\{{msiName}} -Algorithm SHA256
gh attestation verify .\{{msiName}} -R dtwinuz/bitg

If anything differs, don’t run the file — tell us via Telegram or GitHub issues. bitg is distributed only from bitg.uz and GitHub; there is no phone app, so be careful with “new alphabet keyboard” files shared in Telegram chats.

Deploying across an organisation

Silent install via GPO, Intune, SCCM or PDQ:

msiexec /i {{msiName}} /qn /l*v bitg-install.log
msiexec /i {{msiName}} /qn AUTOSTART=0 ADDKEYBOARD=0
msiexec /x {{msiName}} /qn

AUTOSTART=0 keeps the tray app from starting with Windows; ADDKEYBOARD=0 stops the keyboard from being added to each user’s language list automatically. Exit codes are standard: 0 success, 3010 restart recommended, 1603 failure (see the log).

Package managers: winget install bitg is under review and Chocolatey is coming soon — until they are live, use the MSI.

One universal file for every Mac, M-series and Intel alike.

  1. Open the file. The installer is not signed by Apple yet, so macOS refuses to open it the first time. Go to System Settings → Privacy & Security, click “Open Anyway” at the bottom and enter your password.
  2. Install. bitg goes to /Library/Input Methods and adds itself to your input sources. If it doesn’t appear in the menu bar list, log out and back in.
  3. Pick it. Press Control + Space (or the 🌐 key) and choose bitg. If it’s not listed: System Settings → Keyboard → Input Sources → Edit → “+”, then search for “bitg”.

With Homebrew, one command installs it and brew upgrade keeps it current:

brew install --cask dtwinuz/tap/bitg

Or verify and install from the terminal, without the warning dialog:

shasum -a 256 ~/Downloads/{{macName}}
sudo installer -pkg ~/Downloads/{{macName}} -target /

The Mac version is new and hasn’t been tested in many apps yet. If a letter is doubled, lost or a word isn’t converted, tell us the app name on Telegram. bitg stays off in Terminal, iTerm, Warp and other terminals.

apt repository: updates itself

Add it once and new versions arrive with sudo apt upgrade. Packages are signed with our key; apt refuses any file whose signature doesn’t match.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://bitg.uz/apt/bitg.gpg | sudo tee /etc/apt/keyrings/bitg.gpg >/dev/null
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/bitg.gpg] https://bitg.uz/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/bitg.list
sudo apt update && sudo apt install bitg
ibus restart

Key fingerprint: {{aptFingerprint}}. To remove the repository: sudo rm /etc/apt/sources.list.d/bitg.list /etc/apt/keyrings/bitg.gpg.

Browser extension

Can’t install software on your work computer? The bitg extension for Chrome Web Store and Microsoft Edge Add-ons runs the same bitg engine (WebAssembly) offline: a pop-up converter, converting selected text, and converting as you type on the sites you choose. Its content security policy blocks external requests, so text never leaves the browser.

Is there a bitg app for iPhone or Android?

Not yet. On phones we recommend the free Tilmoch keyboard, whose new-alphabet mode inserts ö, ğ, ş, ç automatically; without installing anything, the Turkish (Türkçe) keyboard has all four letters.

Does bitg need the internet or send my text anywhere?

No. The desktop apps and the browser extension convert text on your device; nothing you type is sent or stored. See the privacy policy.

How do I uninstall bitg?

Windows: Settings → Apps → bitg → Uninstall, or msiexec /x; your settings in %APPDATA%\bitg are kept. Linux: sudo apt remove bitg. macOS: sudo rm -rf "/Library/Input Methods/bitg.app", then log out and back in.

Just need to convert a text once?

No install needed: paste it into the online converter, or let your AI assistant do it through the bitg MCP server.
