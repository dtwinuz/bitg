Windows app

  • Your text never leaves the computer. The conversion engine is built into the app; nothing you type is sent anywhere.
  • Update check (since 0.4.0): once a day the app reads bitg.uz/update/stable.json. The request carries only the app version (bitg/0.4.0 (Windows)). Updates are installed only from GitHub Releases and only if the size and SHA-256 match. It can be turned off in settings, at install time (UPDATECHECK=0) or by administrator policy.
  • The “Report a problem” window (since 0.4.0) sends something only when you press “Send”: your message, an optional screenshot and contact, the app version and a random install ID (not your name or device data). Diagnostics (Windows build, number of settings) are added only if you tick the box. The report is delivered to the bitg maintainers’ Telegram chats: Telegram stores it and we do not delete it automatically. To limit spam the server keeps your IP address for 1 hour and the install ID for 1 day, in memory only, then drops them; the message text is not written to the server log (only the ticket number).
  • No text in logs. The log file (%LOCALAPPDATA%\bitg\tsf.log) holds only the time, the app name and the outcome (for example “converted”).
  • Settings stay on your computer: %APPDATA%\bitg\settings.ini and the exceptions list exceptions.txt.
  • Clipboard is used only when you press Ctrl + Shift + Y: the selection is converted, pasted back, and your previous clipboard content is restored.

Online converter

The page downloads the bitg engine (a WebAssembly file) once; after that your text is converted inside the browser. The converter makes no network request with your text. The site’s Content Security Policy allows requests only to bitg.uz and Yandex Metrica, and Metrica never receives text or form input (see below).

Browser extension (Chrome, Edge, Firefox)

  • No network. The bitg engine ships inside the extension; text is converted in your browser and never sent anywhere. The extension’s CSP forbids external requests.
  • No text is stored. Browser sync storage holds only settings: interface language and the list of sites where “convert while typing” is on.
  • It touches a page only when you act (context menu, toolbar button or shortcut), and only that one tab. Convert-while-typing runs only on sites you enable; turning it off also removes the browser permission.
  • The clipboard is write-only: the extension copies the result when the selection is not editable and never reads the clipboard.
  • No analytics, ads or cookies.

MCP server for AI assistants (bitg.uz/mcp)

  • When you connect bitg to Claude, ChatGPT, Gemini or another assistant, the assistant sends the text it wants converted to https://bitg.uz/mcp.
  • The text is converted in memory and returned. It is not written to disk, not logged and not used for anything else. No account, cookie or API key is involved.
  • To limit abuse, the server keeps the caller’s IP address in memory only, for one minute (rate limit: 120 requests per minute), then drops it. Requests to /mcp are not written to the site access log.
  • How the AI service itself (Anthropic, OpenAI, Google and others) stores your conversation is governed by that service’s own terms.

Telegram bot

Messages sent to the bot reach it through Telegram, which is how Telegram works. The bot does not store or log message text; it keeps only an overall message count. A message sent with /fikr is copied to the bitg maintainers’ Telegram chats: Telegram stores it and we do not delete it automatically. So that replies can reach you, the bot keeps in state.json up to 2,000 “maintainer message → chat ID” mappings (oldest dropped first) and the chats with a pending /fikr (15 minutes); for spam protection the chat ID stays in memory for 1 day. For confidential text use the converter or the Windows app instead.

Website

  • Yandex Metrica (since 2026-11-13): which page was opened, where the visit came from, device type, and link and button clicks. This goes to Yandex with the full IP address and Metrica cookies (_ym_*) under Yandex terms. Session replay (Webvisor) and form analytics are off, so nothing typed into the converter or any field is sent. If “Do Not Track” or Global Privacy Control is on, Metrica is not loaded at all.
  • No advertising.
  • The site itself stores only two preferences in your browser: theme and page alphabet.
  • The web server logs page and file requests with a shortened IP address (last part replaced with zero), the page, the time and the browser type, and deletes them after 30 days. The hosting front proxy keeps standard access logs (IP address, time, path, browser type) for up to 30 days for security and abuse prevention. Only aggregate counts (visits per day, downloads per system) are derived from them.
