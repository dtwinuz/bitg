Talab: Ubuntu 22.04+ yoki Debian 12+ (x64). Har PR’da Ubuntu 22.04 va 24.04 da IBus avtomatik sinovdan o‘tadi.

Ubuntu va Debian: bitg (IBus)

  1. O‘rnating. {{debName}} ({{debSizeUz}}) ni yuklab oling: sudo apt install ./{{debName}}, so‘ng ibus restart (yoki tizimdan chiqib qayta kiring).
  2. Kiritish manbasini qo‘shing. Sozlamalar → Klaviatura → Kiritish manbasi qo‘shish → O‘zbek → bitg.
  3. Tanlang va yozing. Super + Probel bilan bitg’ga o‘ting. Yuqori paneldagi til belgisida «ö» turadi.

bitg o‘z tartibiga ega emas — joriy tartibning harflarini oladi. Kirill tartibidan bitg’ga o‘tsangiz, kirillcha yozasiz va so‘z ham yangi lotinga o‘tadi: чой шаҳар → çoy şahar. Parol, PIN, email maydonlari va terminallarda bitg o‘chiq.

apt ombori: o‘zi yangilanib tursin

Ombor imzolangan, kalit izi: {{aptFingerprint}}.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://bitg.uz/apt/bitg.gpg | sudo tee /etc/apt/keyrings/bitg.gpg >/dev/null
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/bitg.gpg] https://bitg.uz/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/bitg.list
sudo apt update && sudo apt install bitg

Keyingi versiyalar odatdagi sudo apt upgrade bilan keladi. Fcitx5 uchun paket nomi: fcitx5-bitg.

KDE va Fcitx5

Fcitx5 ishlatsangiz (KDE Plasma va boshqalar), {{fcitxName}} ni o‘rnating (yoki apt omboridan sudo apt install fcitx5-bitg), so‘ng fcitx5-configtool da «bitg» ni qo‘shing.

Fcitx5 qo‘shimchasi sinov bosqichida: CI’da paket o‘rnatilishi va kutubxona yuklanishi tekshiriladi, lekin Fcitx5’da yozish hali avtomatik sinalmaydi. Natijani GitHub’da yozing.

Arch Linux, Manjaro, EndeavourOS

bitg 0.5.0 dan Arch uchun o‘z pacman ombori (bitg.uz/arch) bilan keladi: bir marta ulanadi, keyin sudo pacman -Syu bilan yangilanadi. Ikkita paket: bitg (IBus va CLI) va fcitx5-bitg. AUR’da hali yo‘q. Ombor ochilgunga qadar paketni manbadan o‘zingiz yig‘ishingiz mumkin:

git clone --depth 1 https://github.com/dtwinuz/bitg.git && cd bitg/packaging/aur
makepkg --syncdeps
sudo pacman -U bitg-[0-9]*.pkg.tar.zst
ibus restart

Keyman: tayyor tartib

Avtomatik o‘girish emas, har harfni o‘zingiz bosmoqchi bo‘lsangiz, bepul Keyman dasturiga bitg jamoasi tayyorlagan Uzbek Latin 2026 klaviaturasini o‘rnating (Linux uchun ham bor). Tartib bitg’dagi «taklif» bilan bir xil: [ → ö, ] → ğ, ; → ş, ' → ç, \ → ʼ; o‘rniga ketgan belgilar o‘ng Alt bilan yoziladi. Bu tartib Senatda ko‘rsatilgan maketga asoslangan, rasmiy standart hali chiqmagan.

Dasturisiz: Turkish Q tartibi

Sozlamalar → Klaviatura → Kiritish manbasi qo‘shish → Turkcha (Turkish Q). Unda ö ğ ş ç alohida tugmada turadi. Kamchiligi: ba’zi belgilar ko‘chadi, i esa nuqtasiz ı yozadi.

Dasturisiz: Compose tugmasi

Compose tugmasi bosilgach, keyingi ikki tugma bitta belgiga birlashadi. GNOME’da yoqish: Sozlamalar → Klaviatura → «Maxsus belgilar yozish» bo‘limidagi Compose Key → qaysi tugma bo‘lishini tanlang (masalan, o‘ng Alt).

Savollar

Ubuntu’da yangi alifboda qanday yozaman?

bitg .deb paketini o‘rnating (sudo apt install ./bitg_…_amd64.deb), so‘ng Sozlamalar → Klaviatura → Kiritish manbasi qo‘shish → O‘zbek → bitg ni tanlang va Super + Probel bilan almashing. Eskicha yozasiz, so‘z tugashi bilan ö ğ ş ç ga o‘tadi.

KDE’da bitg ishlaydimi?

KDE odatda Fcitx5 ishlatadi. Buning uchun alohida fcitx5-bitg paketi bor, uni fcitx5-configtool da qo‘shasiz. Bu qo‘shimcha hozircha sinov bosqichida.

Arch Linux uchun bitg bormi?

Ha. bitg 0.5.0 dan bitg.uz/arch pacman ombori bilan keladi (bitg va fcitx5-bitg paketlari). Unga qadar packaging/aur papkasidagi PKGBUILD bilan makepkg orqali o‘zingiz yig‘asiz. AUR’da hozircha yo‘q.

Compose tugmasi bilan ş qanday yoziladi?

Compose, keyin vergul, keyin s: ş chiqadi. ç uchun Compose, vergul, c; ğ uchun Compose, U, g; ö uchun Compose, qo‘shtirnoq, o. GNOME’da Compose tugmasi Sozlamalar → Klaviatura bo‘limida yoqiladi.
