Har qanday kompyutertayyor matnni onlayn konvertorda o‘giring — o‘rnatish kerak emas

To‘rtta yangi harf: O‘ → Ö, G‘ → Ğ, Sh → Ş, Ch → Ç, tutuq belgisi ʼ qoladi (to‘liq alifbo). Ular Unicode’da bor, shuning uchun shrift va dasturlar ularni allaqachon ko‘rsatadi — qiyini faqat yozish: oddiy klaviaturada bu tugmalar yo‘q.

Windows uchun yangi alifbo dasturi: yuklab olish va o‘rnatish

  1. Yuklab oling. Yuklab olish sahifasidan MSI o‘rnatuvchini oling (Windows 10 va 11, x64). Fayl SHA-256 xeshi o‘sha sahifada, manba kodi va relizlar GitHub’da.
  2. O‘rnating. Faylni ikki marta bosing. O‘rnatuvchi hozircha raqamli imzosiz, shuning uchun «Windows kompyuteringizni himoya qildi» oynasi chiqishi mumkin: «Batafsil» → «Baribir ishga tushirish». Nega bunday ekani: bitg xavfsizmi?
  3. bitg’ni tanlang. Win + Probel bilan kiritish usullari orasidan bitg’ni tanlang (yoki vazifalar panelidagi til belgisini bosing).
  4. Odatdagidek yozing. «o‘zbek», «shahar», «choy» — probel yoki tinish belgisi bosilishi bilan «özbek», «şahar», «çoy» bo‘ladi. Inglizcha so‘z (shop, check), havola va pochta manzili o‘zgarmaydi. Kerak bo‘lmasa — darhol Backspace: asl so‘z qaytadi.

bitg Windows’ning o‘z kiritish usuli (TSF) sifatida ishlaydi, shuning uchun Word, Excel, Telegram, brauzer va boshqa dasturlarda alohida sozlashsiz yozadi. Internet kerak emas: o‘girish kompyuterning o‘zida bo‘ladi, matn hech qayerga yuborilmaydi. Batafsil: Windows klaviaturasi.

ARM (Snapdragon) protsessorli kompyuterlarda bitg hali sinalmagan. Natijani bizga yozing.

Tugma bilan yozmoqchi bo‘lsangiz

bitg ichida tayyor klaviatura tartiblari bor — masalan, Tilmoch tartibida [ → ö, ] → ğ, ; → ş, ' → ç. Avtomatik o‘girish va tartib alohida yoqiladi. Hammasini solishtirish: klaviatura tartiblari. O‘rnatmasdan yo‘llar (Alt kodlari, Word’da Alt + X): Ş, Ç, Ğ, Ö qanday yoziladi.

macOS’da

  1. O‘rnating. .pkg faylni yuklab oling (Apple M va Intel uchun bitta fayl) yoki Homebrew bilan: brew install --cask dtwinuz/tap/bitg. O‘rnatuvchi hozircha Apple imzosiz: macOS ochmasa, «Tizim sozlamalari → Maxfiylik va xavfsizlik» da «Baribir ochish» ni bosing.
  2. Kiritish manbasi o‘zi qo‘shiladi. Menyu satridagi ro‘yxatda ko‘rinmasa, tizimdan chiqib qayta kiring yoki: Tizim sozlamalari → Klaviatura → Kiritish manbalari → Tahrirlash → «+», qidiruvga «bitg» yozing.
  3. Tanlang va yozing. Control + Probel (yoki 🌐 tugmasi) bilan bitg’ga o‘ting va eskicha yozing.

Mac versiyasi sinov bosqichida. Dasturisiz yo‘l: Option + U, so‘ng O → ö; Option + C → ç; ğ va ş uchun «Turkish Q» tartibi (batafsil).

Linux’da (Ubuntu, Debian)

  1. O‘rnating. .deb paketni yuklab oling va o‘rnating: sudo apt install ./{{debName}}. Yangilanib turishi uchun apt omborini ulash ham mumkin.
  2. Kiritish manbasini qo‘shing. Sozlamalar → Klaviatura → Kiritish manbasi qo‘shish → O‘zbek → bitg (IBus). KDE va Fcitx5 uchun alohida paket bor — yuklab olish sahifasida.
  3. Tanlang va yozing. Super + Probel bilan bitg’ga o‘ting.

Talablar: Ubuntu 22.04+ yoki Debian 12+.

Brauzerda: bitg kengaytmasi

Dastur o‘rnatib bo‘lmaydigan kompyuterda (masalan, ishxonada) brauzer kengaytmasi yordam beradi. bitg kengaytmasi Chrome Web Store’da bor. U o‘sha bitg yadrosini (WebAssembly) ishlatadi va internetsiz o‘giradi:

  • Popup o‘giruvchi — matnni joylaysiz, yangi alifbodagi shakli chiqadi.
  • Belgilangan matn — o‘ng tugma menyusi yoki Alt + Shift + Y bilan tahrir maydonidagi matn joyida o‘giriladi.
  • Yozayotganda o‘girish — siz tanlagan saytda yoqiladi (standart holatda o‘chiq).

Google Docs matnni o‘zi chizadi, u yerda yozayotganda o‘girish ishlamaydi — matnni popup’da o‘girib qo‘ying yoki kompyuterga bitg’ni o‘rnating.

Word, Excel fayllarini butunlay o‘girish

Tayyor hujjatni qayta yozish shart emas. bitg buyruq qatorida: bitg file hisobot.docx — yangi nusxa (hisobot.yangi.docx) yaratiladi, formatlash joyida qoladi. .docx, .xlsx, .txt va .md fayllar qo‘llab-quvvatlanadi; avval nima o‘zgarishini ko‘rish uchun --dry-run. Bir-ikki xatboshi bo‘lsa — onlayn konvertor tezroq.

Savollar

Kompyuterda yangi alifboda qanday yozaman?

Eng oson yo‘l — bitg dasturini o‘rnatib, eskicha yozish: so‘z tugashi bilan o‘, g‘, sh, ch yangi harflarga (ö, ğ, ş, ç) o‘tadi. bitg Windows 10/11, macOS 11+ va Ubuntu/Debian uchun bepul; tugma bilan yozish uchun ichida klaviatura tartiblari ham bor.

Yangi alifbo dasturi Windows uchun bepulmi?

Ha. bitg bepul va ochiq kodli (MIT yoki Apache-2.0), kompaniyalarda ham bepul ishlatiladi. Uni bitg.uz/yuklab-olish sahifasidan yoki GitHub relizlaridan yuklab olasiz.

bitg Microsoft Store’da bormi?

Hozir yo‘q: bitg bitg.uz va GitHub’dan MSI o‘rnatuvchi sifatida tarqatiladi. Microsoft Store’dagi boshqa yangi alifbo ilovalari va ularning farqi taqqoslash sahifasida.

Inglizcha so‘zlar buzilmaydimi?

Yo‘q: bitg har so‘zni lug‘at va kontekst bilan tekshiradi. 3 000 ta inglizcha gapda 99,73 % i o‘zgarmay qoldi (o‘lchov 2026-11-12). Xato o‘girilsa, Backspace bosing — asl so‘z qaytadi.

Internet kerakmi?

Yo‘q. O‘girish kompyuterning o‘zida bo‘ladi, yozgan matningiz hech qayerga yuborilmaydi va saqlanmaydi.

Dastur o‘rnatib bo‘lmasa-chi?

Brauzerda bitg kengaytmasini (Chrome Web Store) yoki bitg.uz/konvertor onlayn konvertorini ishlating. Windows’da Alt kodlari bilan ö (Alt 0246) va ç (Alt 0231) ni o‘rnatmasdan yozish mumkin, ğ va ş uchun esa Turkcha Q tartibi kerak.
