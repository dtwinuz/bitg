Windows’da

1. Avtomatik: bitg

bitg — Windows klaviaturasi. Odatdagidek eskicha yozasiz: «shahar», «o‘zbek», «choy». Probel yoki tinish belgisi bosilishi bilan so‘z «şahar», «özbek», «çoy» bo‘ladi. Inglizcha so‘zlar (check, shop), havola va kod o‘zgarmaydi. Kerak bo‘lmasa — Backspace bosing, asl so‘z qaytadi. Batafsil.

2. Bitta tugma bilan: klaviatura tartibi

bitg ichida tayyor tartiblar bor: Tilmoch tartibida [ → ö, ] → ğ, ; → ş, ' → ç, ` → ʼ. Windows’ning o‘zidagi Turkcha Q tartibida esa , → ö, [ → ğ, ; → ş, . → ç (lekin u yerda i tugmasi ı yozadi). Taqqoslash: klaviatura tartiblari.

3. Alt kodlari (o‘rnatmasdan)

Alt ni bosib turib, raqamlar panelida (Num Lock yoqiq) kodni tering:

Linux’da (Ubuntu, Debian)

1. Avtomatik: bitg

bitg Linux’da IBus kiritish usuli sifatida ishlaydi. .deb paketni o‘rnating (sudo apt install ./{{debName}}), so‘ng Sozlamalar → Klaviatura → Kiritish manbasi qo‘shish → O‘zbek → bitg. Yozish Windows’dagidek: so‘z tugashi bilan yangi harflarga o‘tadi, Backspace asl so‘zni qaytaradi.

2. Tugma bilan

Sozlamalar → Klaviatura’dan «Turkcha (Turkish Q)» tartibini qo‘shing — unda ö ğ ş ç alohida tugmada. Yoki Compose tugmasini yoqing: Compose " o → ö, Compose , c → ç.

Mac’da

  • ö — Option + U, so‘ng O (bosh harf uchun Shift + O).
  • ç — Option + C (bosh harf: Option + Shift + C).
  • ğ, ş — standart inglizcha tartibda yo‘q. Tizim sozlamalari → Klaviatura → Kiritish manbalari → «Turkish Q» ni qo‘shing: unda to‘rtala harfning o‘z tugmasi bor.

bitg’ning Mac versiyasi rejada. Hozircha tayyor matnni konvertorda o‘girish mumkin.

Telefonda (Android, iPhone)

Eng ishonchli yo‘l — turkcha klaviatura: turk alifbosida ham Ö, Ğ, Ş, Ç bor va ular alohida tugmada turadi.

  1. Android (Gboard) Gboard sozlamalari → Tillar → Klaviatura qo‘shish → Türkçe → «Q» tartibi. Probel tugmasini bosib turib yoki globus belgisi bilan tilni almashtirasiz.
  2. iPhone Sozlamalar → Umumiy → Klaviatura → Klaviaturalar → Yangi klaviatura qo‘shish → Türkçe. Globus belgisi bilan almashtiriladi.

Ko‘p klaviaturalarda harfni bosib turganda qo‘shimcha variantlar ham chiqadi, lekin ş va ğ har doim ham bo‘lavermaydi — turkcha tartib barqarorroq. bitg’ning telefon versiyasi (avtomatik o‘girish bilan) rejada.

Tutuq belgisi ʼ qanday yoziladi?

Yangi alifboda tutuq belgisi — ʼ (U+02BC). Oddiy klaviaturada u yo‘q. bitg oddiy apostrofni (') so‘z ichida o‘zi ʼ ga almashtiradi: ma'no → maʼno. Tirnoq ichidagi gapga ('Yaxshi tong') tegmaydi.

Harfni boshqa belgi bilan almashtirsa bo‘ladimi?

Yo‘q: ş o‘rniga s yoki ç o‘rniga c yozish so‘zni noto‘g‘ri o‘qitadi. Belgining ko‘rinishi o‘xshash bo‘lsa ham, kodi to‘g‘ri bo‘lishi kerak: qidiruv, saralash va imlo tekshiruvi aynan kodni o‘qiydi. Yuqoridagi barcha yo‘llar to‘g‘ri Unicode belgisini yozadi.
