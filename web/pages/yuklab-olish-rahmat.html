Tizimingizni tanlang — fayl yuklanadi va o‘rnatish qadamlari ko‘rinadi.

Boshlanmadimi? To‘g‘ridan-to‘g‘ri yuklab olish

Windows Mac Linux (IBus) Linux (Fcitx5)

Windows: 3 qadam

  1. Faylni oching. Yuklangan {{msiName}} ni bosing (brauzerning yuklamalar ro‘yxatida yoki «Yuklamalar» papkasida).
  2. «Windows kompyuteringizni himoya qildi» chiqsa — «Batafsil» → «Baribir ishga tushirish». O‘rnatuvchi hozircha raqamli imzosiz; fayl biznikimi — SHA-256 bilan tekshiring.
  3. Klaviaturani tanlang. Win + Probel → «bitg». Endi istalgan dasturda eskicha yozing: «o‘zbek» → «özbek».

Mac: 3 qadam

  1. Faylni oching. «Yuklamalar» dagi {{macName}}. macOS «tekshirib bo‘lmadi» desa: «Tizim sozlamalari → Maxfiylik va xavfsizlik» → pastda «Baribir ochish» → parol.
  2. O‘rnating. bitg kiritish manbalariga o‘zi qo‘shiladi. Ro‘yxatda ko‘rinmasa, tizimdan chiqib qayta kiring.
  3. Tanlang. Control + Probel (yoki 🌐) → «bitg». Bitta fayl Apple M va Intel’da ishlaydi.

Mac versiyasi sinov bosqichida — biror dasturda xato bo‘lsa, dastur nomi bilan yozing.

Linux: 3 qadam

  1. O‘rnating. Fayl turgan papkada: sudo apt install ./{{debName}}
  2. Kiritish tizimini qayta ishga tushiring: ibus restart (Fcitx5’da fcitx5 -r).
  3. Qo‘shing va tanlang. Sozlamalar → Klaviatura → Kiritish manbasi qo‘shish → O‘zbek → bitg; so‘ng Super + Probel. Fcitx5’da: fcitx5-configtool.

Keyingi versiyalar o‘zi kelsin desangiz — apt omborini ulang: sudo apt upgrade bilan yangilanadi.
