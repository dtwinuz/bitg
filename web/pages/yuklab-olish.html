Linux yoki Mac’dasizmi? Ubuntu va Debian uchun .deb paket, Mac uchun .pkg o‘rnatuvchi pastda. Boshqa yo‘l: GitHub Releases sahifasida ham shu fayllar va .sha256 turadi. Manba kodi ochiq — o‘zingiz qurishingiz ham mumkin.

O‘rnatish: 3 qadam

  1. Faylni oching. Yuklangan {{msiName}} ni ikki marta bosing. O‘rnatuvchi barcha foydalanuvchilar uchun ishlaydi.
  2. bitg o‘zi ochiladi. O‘rnatish oxirida bitg ishga tushadi va klaviaturani «O‘zbek (lotin)» tiliga o‘zi qo‘shadi.
  3. Klaviaturani tanlang. Win + Probel bosib, ro‘yxatdan «bitg» ni tanlang. Endi istalgan dasturda eskicha yozing — «o‘zbek» → «özbek».

Yangilash ham shu yo‘l bilan: yangi MSI’ni oching. Ochiq dasturlarni (Chrome, Telegram) yopish va kompyuterni qayta yuklash shart emas.

«Windows kompyuteringizni himoya qildi» oynasi chiqsa

Beta o‘rnatuvchi hozircha raqamli imzosiz, shuning uchun SmartScreen notanish nashriyotchi haqida ogohlantiradi. Oynada «Batafsil» → «Baribir ishga tushirish» ni bosing.

Fayl aynan biznikimi — tekshirish oson. PowerShell’da:

Get-FileHash .\{{msiName}} -Algorithm SHA256

Chiqqan qiymat yuqoridagi SHA-256 bilan bir xil bo‘lishi kerak. Bir belgi farq qilsa ham faylni ochmang va bizga Telegram orqali yozing.

Qaysi dasturlarda ishlaydi?

bitg — Windows kiritish usuli (TSF). Word, Chrome va Edge, zamonaviy Windows ilovalarida to‘liq ishlaydi. Telegram Desktop kabi Qt dasturlarida zaxira yo‘l bilan ishlaydi. Terminallarda (Windows Terminal, PuTTY) standart holatda o‘chiq — u yerda buyruq va parol yoziladi; xohlasangiz sozlamalardan yoqasiz. Batafsil: Windows klaviaturasi.

Kompaniyada ommaviy o‘rnatish

GPO, Intune, SCCM yoki PDQ orqali jim o‘rnatish:

msiexec /i {{msiName}} /qn /l*v bitg-install.log
msiexec /i {{msiName}} /qn AUTOSTART=0 ADDKEYBOARD=0
msiexec /x {{msiName}} /qn

AUTOSTART=0 — tray ilovasi Windows bilan ishga tushmaydi, ADDKEYBOARD=0 — klaviatura foydalanuvchining tillar ro‘yxatiga avtomatik qo‘shilmaydi. Qaytish kodlari standart: 0 muvaffaqiyat, 3010 qayta yuklash tavsiya etiladi, 1603 xato (sababi logda).

O‘chirish

Sozlamalar → Ilovalar → bitg → O‘chirish (yoki msiexec /x). Dastur ochiq oynalarda yuklangan bo‘lsa, o‘chirish bir daqiqagacha cho‘zilishi mumkin — qayta yuklash kerak emas. Shaxsiy sozlamalar (%APPDATA%\bitg) saqlanib qoladi.

Ubuntu va GNOME’da standart kiritish tizimi — IBus. Terminalda:

sudo apt install ./{{debName}}

So‘ng Sozlamalar → Klaviatura → Kiritish manbasi qo‘shish → O‘zbek → bitg va Super + Probel bilan tanlang. Matnni bermaydigan dasturlarda so‘z yozilayotganda tagi chizilgan ko‘rinadi va probel bosilganda yangi alifboda yoziladi. Parol maydonlari va terminallarda bitg o‘chiq turadi.

apt ombori: o‘zi yangilanib turadi

Bir marta ulang — keyingi versiyalar sudo apt upgrade bilan keladi. Paketlar bizning kalitimiz bilan imzolangan; apt imzosi mos kelmagan faylni o‘rnatmaydi.

sudo install -d -m 0755 /etc/apt/keyrings
curl -fsSL https://bitg.uz/apt/bitg.gpg | sudo tee /etc/apt/keyrings/bitg.gpg >/dev/null
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/bitg.gpg] https://bitg.uz/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/bitg.list
sudo apt update && sudo apt install bitg
ibus restart

Fcitx5 uchun oxirgi qatorda sudo apt install fcitx5-bitg. Kalit izi (fingerprint): {{aptFingerprint}}. Omborni olib tashlash: sudo rm /etc/apt/sources.list.d/bitg.list /etc/apt/keyrings/bitg.gpg.

Fcitx5 (KDE va boshqalar) ishlatsangiz: {{fcitxName}} ({{fcitxSizeUz}}) ni o‘rnatib, fcitx5-configtool da «bitg» ni qo‘shing. Bu qo‘shimcha hozircha sinov bosqichida — muammo bo‘lsa Telegram’da yozing.

O‘chirish: sudo apt remove bitg. Sozlamalar ~/.config/bitg da saqlanib qoladi.

Bitta fayl hamma Mac’lar uchun: yangi (Apple M1, M2, M3, M4) va eski (Intel) protsessorlarda ishlaydi — qaysi Mac ekanini bilish shart emas.

  1. Faylni oching. O‘rnatuvchi hozircha Apple imzosiz, shuning uchun macOS «tekshirib bo‘lmadi» deb ochmaydi. «Tizim sozlamalari → Maxfiylik va xavfsizlik» ga o‘ting, pastda «Baribir ochish» ni bosing va parolni kiriting.
  2. O‘rnating. bitg /Library/Input Methods ga yoziladi va kiritish manbalariga o‘zi qo‘shiladi. Menyu satridagi ro‘yxatda ko‘rinmasa, tizimdan chiqib qayta kiring.
  3. Tanlang. Control + Probel (yoki 🌐 tugmasi) bilan «bitg» ni tanlang va eskicha yozing. Ro‘yxatda bo‘lmasa: Tizim sozlamalari → Klaviatura → Kiritish manbalari → Tahrirlash → «+», qidiruvga «bitg» yozing.

Homebrew bilan bitta buyruq: o‘rnatadi, keyin brew upgrade bilan yangilanadi.

brew install --cask dtwinuz/tap/bitg

Terminalda o‘rnatish (ogohlantirish oynasisiz) va faylni tekshirish:

shasum -a 256 ~/Downloads/{{macName}}
sudo installer -pkg ~/Downloads/{{macName}} -target /

Mac versiyasi yangi va hali ko‘p dasturlarda sinalmagan. Biror dasturda harf ikki marta yozilsa, yo‘qolsa yoki so‘z o‘girilmasa — dastur nomi bilan Telegram’da yozing. Terminal, iTerm, Warp va boshqa terminallarda bitg o‘chiq turadi. bitg tanlanganda menyu satridagi kiritish menyusida: bitg’ni yoqish/o‘chirish, uni bitta dasturda o‘chirish, istisno so‘zlar ro‘yxati. O‘chirish: sudo rm -rf "/Library/Input Methods/bitg.app", so‘ng qayta kiring; sozlamalar ~/Library/Application Support/bitg da qoladi.
